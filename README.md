The Student Management System contains code that uses Springboot framework for Java. 
For the storage of the data, MySQL is used as the database and then connected to the Spring using dependencies MySQL Connecter J.
For development of the project, dev tools and spring boot starter jpa dependencies are also included. The project is based on the Maven plugin.
For creating a spring project, find the initializer https://start.spring.io/ and then create a project

The MySQL workbench is connected through Port Number 3306 and localhost uses Postman for CRUD operations on the REST API created on the Port Number 8080.
